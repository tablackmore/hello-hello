About this site

This site presents the text of Hello, hello, hello — Good God, any God by Nigel Blackmore: an exploration of spiritual and religious beliefs throughout mankind's history, the reasons for them, and whether there is evidence for a God of any sort — drawing on religion, philosophy and science.

Start with the contents, look things up in the index, or search the full text.

Page numbers

Page numbers follow the original printed edition. Each printed page is marked in the margin (or inline on a phone), and you can link straight to one: for example https://tablackmore.github.io/hello-hello/chapter-17/#p152.

Pictures

The book's figures are being redrawn or cleared for publication. Where a figure isn't ready yet, its caption is shown with “Image to follow in a later edition.” See the picture credits.

Read it with an AI assistant

The book is also available as an MCP server, so assistants such as Claude can search it, quote it with page numbers and link back here.

Claude Code

claude mcp add hello-hello -- npx -y github:tablackmore/hello-hello

Claude Desktop

Download the Claude Desktop extension (hello-hello.mcpb), then double-click it, or drag it onto Claude Desktop's Settings → Extensions page, and choose Install. Nothing else is needed: Claude Desktop runs it with its own built-in Node.

Or, if you already have Node 18+ installed, add this to claude_desktop_config.json:

{
  "mcpServers": {
    "hello-hello": {
      "command": "npx",
      "args": [
        "-y",
        "github:tablackmore/hello-hello"
      ]
    }
  }
}

Install it on your phone

The book works as an app and can be read offline. On an iPhone or iPad, open this site in Safari, tap the Share button, then Add to Home Screen. On Android, use Chrome's Install app or Add to Home screen. Once it has opened, the whole book, its pictures and search are kept on the device, and the app remembers where you stopped reading.
